# Contributing

Thanks for considering a contribution.

- Open an issue before substantial behavior or API changes.
- Keep changes focused and add or update tests.
- Run `npm run build`, `npm test`, `npm run lint`, and `npm run fixtures:check` before opening a pull request.
- Never commit credentials, session IDs, or responses from a real GetMyMacros account. Fixtures must be deterministic and generated with `npm run fixtures:generate`.
